# 📚 Sistema de Gestión de Estudiantes
Este proyecto es un sistema de gestión de estudiantes que permite agregar estudiantes, asignarles notas, buscar estudiantes por nombre y calcular el promedio de sus notas. Está desarrollado con HTML, CSS y JavaScript. Los datos se guardan en el almacenamiento local del navegador (localStorage).

### 🚀 Funcionalidades

- Agregar Estudiantes 📝
Permite agregar estudiantes con su nombre y grupo.
Los datos se guardan en el almacenamiento local para persistir entre recargas de página.
Buscar Estudiantes 🔍

- Busca un estudiante por su nombre.
  Muestra los detalles del estudiante (nombre y grupo) si se encuentra.
  Agregar Notas 🏅

  Se puede agregar una o más notas para un estudiante.
  Las notas se guardan para cada estudiante.
  Calcular Promedio 📊

  Calcula el promedio de las notas de un estudiante.
  Muestra el promedio con 2 decimales.
  Menú Principal 🏠

- Ofrece acceso directo a todas las funcionalidades: agregar estudiante, buscar estudiante, agregar nota y calcular promedio.
### ⚙️ Estructura del Proyecto

### 1. HTML 🖥️
Cada página HTML contiene formularios para interactuar con las funcionalidades del sistema:

- agreEstudiante.html: Página para agregar estudiantes.
- busEstudiante.html: Página para buscar estudiantes.
- agregarNota.html: Página para agregar notas a los estudiantes.
- promedio.html: Página para calcular el promedio de un estudiante.
- index.html: Página principal con el menú de navegación.
### 2. CSS 🎨
El archivo style.css contiene el diseño básico de la interfaz, utilizando estilos simples y modernos para una mejor experiencia de usuario.

### 3. JavaScript 💻
En el archivo main.js, se manejan las interacciones con el almacenamiento local (localStorage) y se implementan las funciones de agregar estudiantes, buscar, agregar notas, y calcular el promedio.

### 4. LocalStorage 🗃️
Los estudiantes y sus notas se guardan en el localStorage del navegador para que la información persista entre recargas de página.

### 🌟 Funciones Principales
- Agregar Estudiante 🧑‍🎓
Los estudiantes se pueden agregar ingresando su nombre y grupo.
Se guardan en el localStorage para ser consultados más tarde.
- Buscar Estudiante 🔍
Permite buscar a un estudiante por su nombre.
Si el estudiante existe, muestra su nombre y grupo.
- Agregar Nota 📚
Se pueden agregar notas para un estudiante existente.
La nota se guarda y se vincula al estudiante.
- Calcular Promedio 📊
Calcula el promedio de las notas de un estudiante.
Muestra el resultado en pantalla con 2 decimales.
### 📂 Instrucciones de Uso
Clona o descarga este repositorio.
Abre el archivo index.html en tu navegador.
Comienza a interactuar con las diferentes páginas para agregar estudiantes, notas y calcular promedios.
